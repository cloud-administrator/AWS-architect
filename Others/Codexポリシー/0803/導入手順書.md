# ChatGPT デスクトップアプリ／Codex Elevated Sandbox 導入手順書

**対象:** Active Directory ドメイン参加済み Windows 端末、原則 1 台 1 利用者、100 名以上の管理展開  
**方式:** アプリ／ファイル配布は既存ソフトウェア配布製品または SKYSEA、特権セットアップはコンピューター GPO のスケジュールタスクから `NT AUTHORITY\SYSTEM` で実行  
**対象アプリ:** ChatGPT desktop app for Windows  
**手順書版:** 1.3  
**作成日:** 2026-08-03

> **本番移行条件:** 付属 PowerShell は、実際の Windows／AD／GPO／SKYSEA／EDR／Proxy 環境では未実行です。本書の 3 台技術検証、10 台パイロット、25～30 台 Wave 1 を順番に完了し、各ゲートで UAC 0 件、対象誤選定 0 件、Critical 検証失敗 0 件を満たした場合だけ全社展開してください。

## 0. 作業を開始しない条件

次のいずれかに該当する端末は、本手順の対象に入れません。

- 1 台の PC で複数ユーザーに Codex を利用させる必要がある。
- 共有 PC、シフト端末、VDI プールである。
- AD コンピューターオブジェクトの `managedBy` を別用途ですでに使用している。
- 対象ユーザーが対象 PC へ一度も通常ログオンしておらず、既存ローカルプロファイルがない。
- `C:\Users` 配下の全プロファイルへ一括実行する予定である。
- ログオン中のユーザーや最終ログオン履歴から対象者を推測する予定である。
- 端末側ジョブへ Domain Admin 資格情報を登録する予定である。
- 社内コード署名証明書、タイムスタンプ、証明書信頼配布を用意できない。
- Codex CLI の固定版、公式チェックサム、社内 SHA-256 を管理できない。

該当端末は `GG-Codex-Computers-Pilot`／`GG-Codex-Computers-Prod` に追加せず、例外管理へ回します。

### 1.3 実装ファイルの SHA-256 を確認する

署名する前に実行します。

```powershell
Set-Location 'C:\CodexDeployment\Kit'

$Failures = New-Object System.Collections.Generic.List[string]
$VerifiedCount = 0

foreach ($Line in Get-Content -LiteralPath '.\SHA256SUMS.txt') {
    if ([string]::IsNullOrWhiteSpace($Line)) { continue }

    $Match = [regex]::Match($Line.Trim(), '^([0-9a-fA-F]{64})\s+(.+)$')
    if (-not $Match.Success) {
        $Failures.Add("SHA256SUMS 形式不正: $Line")
        continue
    }

    $Expected = $Match.Groups[1].Value.ToLowerInvariant()
    $Name = $Match.Groups[2].Value.Trim()
    $Path = Join-Path (Get-Location) $Name
    $VerifiedCount++

    if (-not (Test-Path -LiteralPath $Path -PathType Leaf)) {
        $Failures.Add("不存在: $Name")
        continue
    }

    $Actual = (Get-FileHash -LiteralPath $Path -Algorithm SHA256).Hash.ToLowerInvariant()
    if ($Actual -ne $Expected) {
        $Failures.Add("不一致: $Name Expected=$Expected Actual=$Actual")
    }
}

if ($VerifiedCount -eq 0) {
    $Failures.Add('SHA256SUMS に検証対象がありません。')
}
if ($Failures.Count -gt 0) {
    $Failures | ForEach-Object { Write-Error $_ }
    throw '実装ファイルの SHA-256 検証に失敗しました。'
}

Write-Host "実装ファイルの SHA-256 検証に合格しました。Files=$VerifiedCount" -ForegroundColor Green
```

失敗した場合は作業を止め、ZIP を再取得します。以後、コード署名を付けると PS1 の SHA-256 は変わります。

### 2.5 管理端末で使用する 3 スクリプトへ署名する

```powershell
$Thumbprint = '<40_HEX_THUMBPRINT>' -replace '\s',''
$TimestampUrl = '<TIMESTAMP_URL>'
$Cert = Get-Item "Cert:\CurrentUser\My\$Thumbprint"

$AdminScripts = @(
    'C:\CodexDeployment\Kit\Set-CodexDeviceUserMapping.ps1',
    'C:\CodexDeployment\Kit\Get-CodexOfficialPackage.ps1',
    'C:\CodexDeployment\Kit\New-CodexDeploymentPayload.ps1'

foreach ($File in $AdminScripts) {
    $Signature = Set-AuthenticodeSignature `
        -FilePath $File `
        -Certificate $Cert `
        -TimestampServer $TimestampUrl `
        -HashAlgorithm SHA256

        throw "署名に失敗しました: $File / Status=$($Signature.Status)"

}

$AdminScripts | ForEach-Object {
    Get-AuthenticodeSignature -LiteralPath $_ |
        Select-Object Path,Status,@{n='Thumbprint';e={$_.SignerCertificate.Thumbprint}}
} | Format-Table -AutoSize
```

合格条件:

```text

すべて Thumbprint = <40_HEX_THUMBPRINT>
```

## 5. 対象ユーザーの既存 Windows プロファイルを確認する

### 5.1 対象ユーザーを一度通常ログオンさせる

各パイロット PC で次を行います。

1. `managedBy` に登録した本人が通常ログオンします。
2. デスクトップ表示まで待ちます。
3. サインアウトします。
4. 管理者が管理 PowerShell を開きます。

### 5.2 AD SID と `Win32_UserProfile` を照合する

`<SAM_ACCOUNT_NAME>` を置換して実行します。

```powershell
Import-Module ActiveDirectory
$User = Get-ADUser -Identity '<SAM_ACCOUNT_NAME>' -Properties SID
$User.SID.Value

Get-CimInstance Win32_UserProfile |
    Where-Object { $_.SID -eq $User.SID.Value -and -not $_.Special } |
    Select-Object SID,LocalPath,Loaded,Special,Status
```

合格条件:

```text
該当行 = 1 件
LocalPath = 実在するローカル絶対パス
Special = False
Status = 0
```

ローミングプロファイルを明示許可する設計へ変更しない限り、Status に `2` が含まれる端末も対象外です。該当 0 件、2 件以上、一時／強制／破損プロファイルはパイロットから外します。

`C:\Users\ユーザー名` を手作業で生成しません。後続スクリプトは SID 一致した `LocalPath` を使用します。

### 5.3 プロビジョニング前の全プロファイル状態を記録する

各パイロット PC の管理 PowerShell で実行します。旧プロファイルを変更していないことを後で機械的に比較するための基準値です。基準値取得から第 13.4 節の比較完了まで、対象者以外をログオンさせず、旧プロファイルを別作業で変更しません。

```powershell
$BaselineRoot = 'C:\ProgramData\Company\CodexProvisioning'
$BaselinePath = Join-Path $BaselineRoot 'pre-provision-profile-baseline.json'
New-Item -ItemType Directory -Force -Path $BaselineRoot | Out-Null

function Get-ProfileSnapshot {
    Get-CimInstance Win32_UserProfile |
        Where-Object { -not $_.Special -and -not [string]::IsNullOrWhiteSpace([string]$_.LocalPath) } |
        ForEach-Object {
            $CodexHome = Join-Path ([string]$_.LocalPath) '.codex'
            $ConfigPath = Join-Path $CodexHome 'config.toml'
            $MarkerPath = Join-Path $CodexHome '.sandbox\setup_marker.json'
            $SecretsPath = Join-Path $CodexHome '.sandbox-secrets\sandbox_users.json'
            [pscustomobject]@{
                sid = [string]$_.SID
                localPath = [string]$_.LocalPath
                codexHomeExists = Test-Path -LiteralPath $CodexHome -PathType Container
                configExists = Test-Path -LiteralPath $ConfigPath -PathType Leaf
                configLastWriteUtc = if (Test-Path -LiteralPath $ConfigPath -PathType Leaf) {
                    (Get-Item -LiteralPath $ConfigPath).LastWriteTimeUtc.ToString('o')
                } else { $null }
                markerExists = Test-Path -LiteralPath $MarkerPath -PathType Leaf
                markerLastWriteUtc = if (Test-Path -LiteralPath $MarkerPath -PathType Leaf) {
                    (Get-Item -LiteralPath $MarkerPath).LastWriteTimeUtc.ToString('o')
                } else { $null }
                secretsFileExists = Test-Path -LiteralPath $SecretsPath -PathType Leaf
            }
        }
}

Get-ProfileSnapshot |
    ConvertTo-Json -Depth 5 |
    Set-Content -LiteralPath $BaselinePath -Encoding UTF8

& "$env:SystemRoot\System32\icacls.exe" $BaselineRoot /inheritance:r /grant:r `
    '*S-1-5-18:(OI)(CI)F' `
    '*S-1-5-32-544:(OI)(CI)F' /T /C | Out-Null
if ($LASTEXITCODE -ne 0) { throw "基準値ファイルの ACL 設定に失敗しました: $BaselinePath" }

Get-Content -LiteralPath $BaselinePath -Raw | ConvertFrom-Json |
    Format-Table sid,localPath,codexHomeExists,configExists,markerExists,secretsFileExists -AutoSize
```

合格条件:

```text
pre-provision-profile-baseline.json が存在
対象 SID を含む通常プロファイルが 1 件
旧／退職者プロファイルの現在状態が記録済み
sandbox_users.json の内容は未読・未出力
```

`requirements.toml` は UTF-8 BOM なしで保持します。Windows PowerShell 5.1 の `Set-Content -Encoding UTF8` で上書きすると BOM が付くため使用しません。次で確認します。

```powershell
$RequirementsPath = 'C:\CodexDeployment\Kit\requirements.toml'
$Bytes = [IO.File]::ReadAllBytes($RequirementsPath)
$HasUtf8Bom = ($Bytes.Length -ge 3 -and $Bytes[0] -eq 0xEF -and $Bytes[1] -eq 0xBB -and $Bytes[2] -eq 0xBF)
```

```powershell
                localPath = [string]$_.LocalPath
                codexHomeExists = Test-Path -LiteralPath $CodexHome -PathType Container
                configExists = Test-Path -LiteralPath $ConfigPath -PathType Leaf
                configLastWriteUtc = if (Test-Path -LiteralPath $ConfigPath -PathType Leaf) {
                    (Get-Item -LiteralPath $ConfigPath).LastWriteTimeUtc.ToString('o')
                } else { $null }
                markerExists = Test-Path -LiteralPath $MarkerPath -PathType Leaf
                markerLastWriteUtc = if (Test-Path -LiteralPath $MarkerPath -PathType Leaf) {
                    (Get-Item -LiteralPath $MarkerPath).LastWriteTimeUtc.ToString('o')
                } else { $null }
                secretsFileExists = Test-Path -LiteralPath $SecretsPath -PathType Leaf
            }
        }
}

$After = @(Get-ProfileSnapshot)
$Unexpected = New-Object System.Collections.Generic.List[object]
$Fields = @(
    'codexHomeExists',
    'configExists',
    'configLastWriteUtc',
    'markerExists',
    'markerLastWriteUtc',
    'secretsFileExists'
)

foreach ($Old in $Before | Where-Object { [string]$_.sid -ne [string]$State.targetSid }) {
    $Now = @($After | Where-Object { [string]$_.sid -eq [string]$Old.sid })
    if ($Now.Count -ne 1) {
        $Unexpected.Add([pscustomobject]@{
            sid = $Old.sid
            localPath = $Old.localPath
            field = 'profileCount'
            before = 1
            after = $Now.Count
        })
        continue
    }
    foreach ($Field in $Fields) {
        if ([string]$Old.$Field -cne [string]$Now[0].$Field) {
            $Unexpected.Add([pscustomobject]@{
                sid = $Old.sid
                localPath = $Old.localPath
                field = $Field
                before = $Old.$Field
                after = $Now[0].$Field
            })
        }
    }
}

$Unexpected | Format-Table -AutoSize
if ($Unexpected.Count -gt 0) {
    throw "対象 SID 以外のプロファイルに変更を検出しました。Count=$($Unexpected.Count)"
}
Write-Host '対象 SID 以外のプロファイル変更はありません。' -ForegroundColor Green
```

合格条件は `Unexpected.Count = 0` です。`sandbox_users.json` は存在情報だけを比較し、内容を読み取りません。

### 13.5 Fail Closed を 1 台で確認する

## 19. よくある障害を処理する

### 19.1 UAC が表示される

1. 利用者が `codex sandbox setup` を手動実行していないことを確認します。
2. GPO タスクが SYSTEM／Highest であることを確認します。
3. `state.json`、`setup_marker.json`、`sandbox_users.json` を確認します。
4. ChatGPT アプリ更新後に setup version 差異が発生していないか確認します。
5. 承認済み CLI／アプリの組合せで 3 台から再パイロットします。

UAC が 1 件でも再現するリングは停止します。

### 19.2 Windows error 1385

1. 正常端末と `gpresult` を比較します。
2. ローカルセキュリティポリシーのログオン権と拒否権を比較します。
3. EDR／セキュリティベースラインの差を確認します。
4. `Everyone` へ広いログオン権を付与しません。
5. 修正を 3 台で再検証します。

### 19.3 EDR が helper を隔離する

次の正規パス、署名者、固定ハッシュを EDR 管理画面で確認します。

```text
C:\Program Files\OpenAI\CodexCLI\bin\codex.exe
C:\Program Files\OpenAI\CodexCLI\codex-resources\codex-command-runner.exe
C:\Program Files\OpenAI\CodexCLI\codex-resources\codex-windows-sandbox-setup.exe
```

パスだけの広い除外ではなく、署名者、固定ハッシュ、正規パスを組み合わせた最小の許可ルールを作成します。

### 19.4 署名が無効になる

1. 対象ファイルを署名後に編集していないか確認します。
2. タイムスタンプサーバーへ到達できたか確認します。
3. ルート／中間 CA と署名者証明書が `LocalMachine` に配布済みか確認します。
4. GPO 引数の Thumbprint に空白がなく、署名者と一致することを確認します。
5. 修正後、再署名して再配布します。
