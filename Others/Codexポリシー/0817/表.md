### 判定記号

| 記号 | 意味                                    |
| -- | ------------------------------------- |
| ○  | そのクライアントに正式な機能または専用の管理画面がある           |
| △  | 一部利用可能、別の方法で代替可能、またはOS・プラン・権限などの条件がある |
| ×  | そのクライアントには同等の正式な機能や専用画面がない            |

# 4. CLIまたはVS Code拡張機能が優れている機能

| 機能                            | ChatGPTデスクトップアプリ | Codex CLI | VS Code拡張機能 | 説明                                                                                                                                                                                               |
| ----------------------------- | ---------------: | --------: | ----------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **非対話実行・スクリプト・CI/CD**         |                × |         ○ |           × | Codex CLIの`codex exec`は、非対話でCodexを実行し、シェルスクリプト、バッチ処理、CI/CDなどに組み込むための正式なインターフェースです。ChatGPTデスクトップアプリとVS Code拡張機能には、同等の非対話コマンドラインインターフェースはありません。                                                    |
| **現在開いているファイル・選択範囲の自動コンテキスト** |                △ |         △ |           ○ | VS Code拡張機能は、エディターで現在開いているファイル、選択範囲、IDE上の差分などを直接コンテキストとして扱えます。CLIでは対象ファイルや範囲をコマンドやプロンプトで指定する必要があります。ChatGPTデスクトップアプリでも、IDEとの連携状況によってエディターコンテキストを利用できる場合がありますが、VS Code拡張機能ほどIDEに直接統合された操作ではありません。 |
| **コードレビューの表示**                |                ○ |         ○ |           ○ | `/review`などによるコードレビューは3種類すべてで利用できます。ただし、表示方法が異なります。ChatGPTデスクトップアプリは専用画面、CLIはターミナル上、VS Code拡張機能はコードや変更箇所に近いIDE上で結果を確認します。                                                                        |

## 用途別の整理

| 主な用途                     | 適している利用方法            | 理由                                 |
| ------------------------ | -------------------- | ---------------------------------- |
| CI/CDから自動的にコードレビューを実行する  | **Codex CLI**        | `codex exec`を使用して、非対話で実行できます。      |
| 定型的なコード修正や調査をスクリプト化する    | **Codex CLI**        | シェルスクリプトやバッチ処理に組み込みやすいためです。        |
| サーバーや開発コンテナ内でCodexを使用する  | **Codex CLI**        | GUIを必要とせず、ターミナル環境で使用できます。          |
| 現在編集しているコードについて質問する      | **VS Code拡張機能**      | 開いているファイルや選択範囲をコンテキストとして渡しやすいためです。 |
| コードの差分を確認しながら修正する        | **VS Code拡張機能**      | エディター上でコードと変更内容を近い位置で確認できます。       |
| 複数のプロジェクトや並行タスクをまとめて管理する | **ChatGPTデスクトップアプリ** | 複数のチャット、プロジェクト、タスクを統合画面で管理できます。    |
