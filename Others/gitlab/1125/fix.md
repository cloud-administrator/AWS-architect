    • Label・Milestone の初期の扱い：Label および Milestone は、Issue を無効化しても Merge Request で利用できる（個別に無効化する設定はない）。初期リリースでは利用ルールで使用を禁止し、Issue の導入時に Label 体系（7 章）とあわせて利用を開始する。
    • 個人用 Snippet の初期の扱い：Project の Snippet は設定で無効化できるが、個人用 Snippet（Personal Snippet）の作成を無効化する設定は Self-Managed の管理設定に見当たらない。導入するバージョンに無効化する設定がない場合は、利用ルールで作成を禁止する。あわせて、利用者が作成できる Snippet の可視性は Private に限定する。
